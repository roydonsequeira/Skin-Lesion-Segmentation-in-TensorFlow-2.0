## Pair Extraordinaire

GitHub requires a **different GitHub user** as co-author on a merged PR commit.

1. Use a friend’s account **or** a second GitHub account you control.
2. Get their GitHub noreply email: GitHub → Settings → Emails → `12345678+username@users.noreply.github.com`
3. Amend a commit before merging:

```bash
git commit --amend -m "Add contributing guidelines

Co-authored-by: Friend Name <12345678+username@users.noreply.github.com>"
```

4. Open a PR and merge it.

Badges can take up to 24 hours to appear on your GitHub profile.
