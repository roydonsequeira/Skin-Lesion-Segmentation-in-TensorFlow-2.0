# ResU-Net Results

Sample evaluation outputs from the ResU-Net model on the ISIC 2018 test set.

Each image shows three panels side by side:

1. **Input** — original dermoscopic image  
2. **Ground truth** — manual segmentation mask  
3. **Prediction** — model output mask
